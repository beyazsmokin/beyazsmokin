# Excel şablonları

Kurulumda bu klasördeki dosyalar `.sistem/sablonlar/` altına kopyalanır.

- `analiz.xlsx` varsa `scripts/excel_rapor.py` raporu bu şablona yazar:
  şablondaki sayfa adları (Özet, Yeterlilik, Teknik, Mali, Riskler, Metraj,
  Metraj İdare, Metraj Hesap, Kesif) eşleşirse veriler o sayfaya eklenir.
- Şablon yoksa betik kendi biçimli çalışma kitabını oluşturur.
