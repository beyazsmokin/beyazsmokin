# Simge

- `ikon.png` — 1024x1024 saydam PNG (macOS, Linux ve genel kullanım)
- `ikon.ico` — 16'dan 256'ya Windows simge dosyası (`desktop.ini` bunu kullanır)
- `ikon-kaynak.jpg` — kullanıcının verdiği özgün görsel

Simge değişirse `ikon.png` ve `ikon.ico` birlikte güncellenir; kurulum betiği
klasöre bunları atar.
